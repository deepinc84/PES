# Project page baseline

Dynamic PES project pages should follow the Trusted Roofing project architecture rather than a generic landing-page stack: breadcrumbs, project hero, project summary, staged photo gallery, project-specific FAQ, structured data, internal links to the service/project hub, and CTA. SEO metadata should be project-specific, including canonical, Open Graph/Twitter title/description/image, and public privacy-safe location data where appropriate.
